# Galaxy-E02-tools

星舰 7（E02）Android 9 车机连接与命令回传助手。应用内名称为「E02 AI 连接助手」，当前版本 1.5，包名 `com.e02.rootconsole`。

已在 2025 款星舰 7、Flyme Auto 2.5.0、1920×1080 屏幕验证基础功能；其他车型及系统版本尚未验证。

## 功能

- 同一 Wi-Fi 下通过网页执行命令，返回标准输出、错误输出、退出码及耗时。
- 每次会话生成四位连接码；普通权限和 root 权限按本次会话选择。
- 使用已有的 root 环境启动独立桥接进程，授权时长可选小时、分钟或永久。
- 前台服务、唤醒锁和可拖动的半透明悬浮保活窗。
- 点击悬浮窗截图到下载目录；截图时隐藏悬浮窗，完成后恢复。长按返回应用。
- 读取有线 ADB 模式和对指定电脑的无线 ADB 放行规则；提供独立开关。

## 使用

1. 安装 APK，连接与电脑相同的 Wi-Fi，允许悬浮窗权限。
2. 选择 root 授权时长，复制应用生成的桥接命令。
3. 在已经具备 root 命令执行能力的工具中粘贴并运行，例如 EVCC 的 ROOT 执行。返回助手检查 root 状态。也可尝试系统已有 `su`。
4. 填写电脑的 IPv4 地址后读取或开启无线 ADB；电脑执行 `adb connect <车机IP>:5555`。
5. 勾选本次 root 权限（按需），启动命令回传，在电脑打开显示的网址并输入连接码。

本应用不会自行获取 root，也不会向 EVCC 或应用管家申请系统级授权。桥接是由已有 root 进程执行生成的命令后启动的。停止回传会结束桥接，旧连接码随即失效；永久时长指桥接无自动到期，不代表跨重启持久化。

## ADB 和截图行为

无线 ADB 使用 `wlan0`、TCP 5555 和独立 `E02_WIFI_ADB` 防火墙链，只放行填写的电脑。关闭无线连接会阻断 Wi-Fi 上的 5555，不停止有线 ADB。电脑或车机 IP 改变后需重新配置。页面中的无线状态表示规则是否允许当前填写的电脑，不代表已实测电脑到车机的连接。

有线开关检查 `/vendor/bin/change_usb_mode.sh` 是否存在，通过厂家属性 `persist.vendor.setusbmode` 切换。必要时重新插拔 USB；属性状态不代表 USB 已成功枚举。应用不修改厂家脚本、不刷写分区，未验证其他车辆的 USB 属性。

截图文件名为 `Download/E02-日期-时间.png`。先写临时文件，再完成重命名，避免读取到未完成的截图。截图需要可用的 root 桥接或 `su`。

前台服务及悬浮窗用于维持进程，系统仍可能终止后台应用。项目没有车辆控制、CarPlay、HUD 或仪表盘接管功能。

## 构建

需要 Python 3、JDK 17，以及官方 Android SDK 的 API 28 平台和 build-tools 34.0.0。无需 Gradle 或第三方 Java 依赖。

设置 `JAVA_HOME`、`ANDROID_HOME` 后执行：

```sh
python build.py
```

也可以显式传入路径：

```sh
python build.py --java-home "<JDK17目录>" --android-jar "<SDK>/platforms/android-28/android.jar" --build-tools "<SDK>/build-tools/34.0.0"
```

产物为 `dist/Galaxy-E02-tools-1.5.apk`。第一次构建会生成仅保存在 `.local/` 的开发签名。请保留该文件用于后续覆盖更新；不同签名不能直接覆盖之前安装的版本。源码不包含已安装版本的私钥。

## 验证

Windows 桌面测试通过 PowerShell 模拟命令执行：

```sh
python tests/run-tests.py --java-home "<JDK17目录>"
```

覆盖 HTTP 认证、跨来源拒绝、UTF-8 回传、错误码、命令超时、输出上限、并发限制、桥接传输、授权到期及 ADB 命令范围。桌面测试不验证实际 Android root 授权或厂家 USB 枚举。

## 代码结构

`src/` 为 Android Java 源码、清单、资源及网页；`tests/` 为桌面测试；`build.py` 编译、对齐并签名 APK。

局域网页面使用 HTTP，适合可信的私人 Wi-Fi。四位码不能代替加密传输；root 会话能执行具有 root 权限的命令。失败认证触发短暂限速，停止会话即作废连接码。桥接只监听回环地址，使用单独的随机密钥。
