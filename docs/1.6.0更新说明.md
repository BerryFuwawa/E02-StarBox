# 1.6.0 候选版

- 新增「连接 / 远程 / 设置」菜单，增大字号与控件，只调整本软件显示。
- 悬浮窗默认开启；轻点返回，长按截图，拖动移动，支持恢复中央。
- 新增红色「退出程序及后台」，停止所有星匣后台任务。
- 无线 ADB 按当前接口和指定电脑 IP 放行，检查地址、规则与监听变化，修正旧规则清理命令。
- 新增 frpc 0.71.0，自建私密 STCP 或导入第三方配置，连接网页和 ADB。
- 新增自动和手动更新、右下角下载提示、文件验证与安装确认。
- 新增五条 GitHub 加速预设、自定义 HTTPS 域名，检查和下载使用同一选择。

原签名支持覆盖安装。当前尚未发布，GitHub 版本文件未上线。真实热点无线链路和公网 FRP 待补充验证。
