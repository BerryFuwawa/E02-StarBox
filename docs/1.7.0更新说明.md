# v1.7.0 更新说明

2026-10-06，versionCode 10。保留原包名和发布签名，可覆盖旧版并保留配置。

## 新增与改进

- 名称统一为 E02星匣 / E02-Starbox，仓库使用 E02-StarBox。
- 重做轻量石墨深色界面，固定连接、远程、设置菜单，统一圆角弹窗和按钮。
- 手机助手支持扫码配对、星匣输入框填写、双向复制及结果反馈；Token 和密钥默认遮罩。
- EVCC、应用管家两种临时 Root 授权入口；双列操作说明、小时／分钟及不设时间上限。
- ADB 显示实际状态和灯色，电脑 IP 增加「确认并应用」，编辑地址与生效地址分开。
- 地址与端口统一小数字键盘，可按需调用车机输入法。
- FRP 支持自建私密连接及第三方配置导入，自建表单支持可选用户名；分别显示车机端口和访问入口。
- 修正换网后的 ADB 维护：暂停不匹配的局域网电脑访问时保留 FRP 通道，返回同网尝试恢复已保存电脑地址。
- 悬浮窗默认开启，点按打开、长按截图、拖动移动，可关闭或恢复居中；完善权限页不存在时的提示。
- 自动／手动检查 GitHub 更新、加速线路、安装包验证与安装确认。
- 首次启动风险告知、设置初始化入口，以及更直接的状态和错误提示。

## 升级后注意

命令网页默认端口为 8875，电脑端 FRP ADB 入口为 8556；无线 ADB 5555、服务器 7000 保留默认。以应用当前显示的地址为准。

自建服务器升级后重新复制电脑端配置；第三方配置若引用旧网页端口，需自行更新。手机助手仅局域网使用。

「不设时间上限」不是永久 Root；结束提权、退出程序及后台或车机重启后仍会失效。

本地已经安装 versionCode 10 的用户不会收到同 code 自动更新提示；可手动下载原签名 APK 覆盖。
