# v1.7.1 更新说明

versionCode 11。保留原包名、签名和配置，可覆盖 v1.7.0。已安装 code11 测试版的用户请手动覆盖本次安装包，以获得最终图标；同版本不会再次提示自动更新。

- 沿用 E02 标识，图标四周改为圆角；提供与图标同色的长方形卡片资源，避免白色留边。
- Root 提权卡片置顶，ADB 连接与局域网命令回传并排位于下方。最新截图和安装包核对见 [布局调整](1.7.1布局调整.md)。
- 授权简化为「复制提权命令、重新检测 Root、结束提权」，不再选择时长。结束提权、退出或重启后仍可能需要重新授权。
- 停止网页回传后保留当前 Root 授权，重新选择 Root 模式即可启动；普通网页不会自动变成 Root 网页。
- ADB 端口、电脑 IP 放行和未知状态分别显示；跨网段放行不再被后台维护撤回。
- 自建远程页面直接选择 ADB／网页通道，点击启动后准备服务；已有可用 ADB 不要求星匣先取得 Root。
- FRP 使用本机入口，不再要求车机连上 Wi-Fi；支持使用车机流量连接服务器。网络变化时更新自动 DNS 并重新连接。

升级前运行的限时授权不会自动延长。请复制并执行新版提权命令，之后以重新检测结果为准。旧限时启动命令会提示重新复制。

使用方法：[Root 与手机助手](教程/Root授权与手机助手.md)、[ADB 与网页](教程/ADB与命令回传.md)、[FRP 远程](教程/FRP远程连接.md)。本批实际测试和未测场景见 [v1.7.1 验证记录](1.7.1验证记录.md)。
