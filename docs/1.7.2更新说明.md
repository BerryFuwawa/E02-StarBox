# v1.7.2 更新说明

## 更新内容

- 沿用 E02 标识，图标四周改为圆角，新增同色长方形卡片资源。
- 包含此前未发布 v1.7.1 的修正：Root 提权置顶、授权不再计时、停止网页回传保留授权、实际 ADB 状态和跨网段放行、自建远程直接选择网页／ADB 通道、FRP 本机入口及网络变化处理。
- 提升到 versionCode 12，已安装 code10 或 code11 的用户可以检查更新。原包名、原签名，可覆盖安装并保留配置。

## 安装与教程

下载 `E02-Starbox-v1.7.2.apk`。从软件内更新时，检查新版 → 点击右下角提示下载 → 校验通过 → 确认安装。安装后重新打开星匣；若 Root 或远程服务已停止，按页面重新授权和启动。
