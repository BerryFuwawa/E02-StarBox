# v1.7.3 更新说明

本次主要改善版本更新体验，修复部分 Flyme Auto 车机点击安装时闪退的问题。

- **修复安装闪退**：软件内更新前请先完成 Root 授权，确认后即可安装。
- **简化更新提醒**：发现新版时，右下角显示一行提示；点击查看更新内容，再选择下载。已是最新版时不显示提醒。
- **新增镜像站自动测试**：下载不畅时，可在设置中测试镜像站，找到可用线路后由你决定是否使用。
- **安装后自动清理**：安装包保存在下载文件夹，安装成功后自动删除；取消安装或安装失败时保留，方便重试。

**如何升级**：如果旧版点击安装会闪退，请先[下载 v1.7.3 安装包](https://github.com/BerryFuwawa/E02-StarBox/releases/download/v1.7.3/E02-Starbox-v1.7.3.apk)，通过 EVCC 或应用管家覆盖安装，已有设置保留。
