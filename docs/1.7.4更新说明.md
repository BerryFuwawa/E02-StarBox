# v1.7.4 更新说明

- 新增「软件打开自启内网穿透」，重新启动星匣时使用已保存配置尝试连接，默认关闭。
- 新增独立授权入口；车机本机已有 Root ADB 时，可在确认后建立星匣自己的 Root 服务。
- 后台保活、状态栏入口、悬浮窗和开机自启集中到「后台」页面。
- 开机自启不再限制主动退出，退出后保留勾选；退出前只需关闭星匣后台保活。
- 暂时隐藏、停用熄火后远程保活，锁车或休眠后请检查实际连接状态。
- 跨网段 IP 提示改为莫兰迪黄色，服务器类型增加清晰的下拉入口。
- 修复车机缺少文件选择器时点击导入闪退，提示改用手机助手填写或导入配置。

支持原签名覆盖安装，保留已有设置。独立授权需要已有 Root ADB，不能用于原厂系统首次解锁 Root。

使用方法见[后台与自动连接](教程/后台与自动连接.md)、[Root 授权与手机助手](教程/Root授权与手机助手.md)；实际测试范围见[验证记录](1.7.4验证记录.md)。
