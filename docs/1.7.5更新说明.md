# v1.7.5 更新说明

- 修复无线 ADB 关闭后状态仍为绿色、文字与开关按钮不一致的问题，操作后按实际检测结果显示。
- 优化无线 ADB 的开启、关闭及后台恢复，关闭局域网访问时保留内网穿透连接。
- 操作按钮增加清晰的按压反馈；测试镜像站时立即显示当前进度，避免重复点击。
- 无线 ADB 的异常提示统一为柔和黄色；没有局域网地址时，明确提示先连接 Wi-Fi 或开启车机热点。
- 暂时隐藏并停用熄火后远程保活，保留普通后台保活、开机自启及打开软件自动连接内网穿透。

支持官方旧版覆盖安装，保留已有设置。熄火、休眠或系统清理后台后，连接仍可能中断；请重新打开星匣检查并恢复。

使用方法见 [ADB 与命令回传](教程/ADB与命令回传.md)、[后台与自动连接](教程/后台与自动连接.md)。
