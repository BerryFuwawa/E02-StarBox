# v1.7.6 更新说明

- 支持系统开机和车辆自然唤醒后恢复星匣后台、状态栏入口及已启用的远程连接。
- 完善断网、换网后的连接恢复；手动停止的通道保持停止。
- 增加无感悬浮窗：全透明、不接收触摸，需要先开启保活悬浮窗。
- 完善软件内检查、下载、校验和确认安装流程。
- 安装失败时显示具体原因，并提供重试和其他更新方式；更新说明末行保留安装帮助，方便旧版用户查阅。
- 保留独立 Root 授权、应急提权命令和最多七天的事件日志。
- 整理后台页面，集中显示恢复与连接状态；不包含仪表、HUD自定义显示或投屏。
- 初始化流程已完成实车验证：清除星匣配置和授权后关闭，再次打开显示首次风险告知。

支持官方旧版覆盖安装，保留已有配置。自动恢复需要开启相应后台功能并具备可用授权、供电和网络；正常休眠或断电期间不保证远程在线。
