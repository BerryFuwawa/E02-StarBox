# FRP 公网通道验证

2026-10-06，E02星匣1.7.0/code10，2025星舰7/Flyme Auto2.5.0/Android9。

使用用户提供的frps服务器和Token，使用独立测试用户名，TLS+STCP私密连接。实际令牌、穿透密钥及设备配置不写入本记录或公开源码。当前通过第三方TOML配置入口运行，配置加入user；自建配置界面尚无用户名输入框，不能用它重新保存来覆盖本次导入配置。

车机登录和网页/ADB代理注册成功，电脑visitor登录成功。以下操作访问电脑loopback visitor端口，经公网frps中转到车机，未直接访问车机局域网地址：

- 网页入口 http://127.0.0.1:8875，普通id命令连续3次通过。
- 同一网页入口，Root id命令连续3次通过，返回uid=0。
- ADB入口127.0.0.1:8556，连接及id命令连续3次通过，返回uid=0。
- 网页未开启本次Root执行时返回403，停止回传、允许Root并重启会话后通过。此项是权限检查，不是代理故障。

HTTP18080/HTTPS18443代理入口本次未使用或验收。服务器15分钟要求指时钟误差，不是连接或心跳间隔；电脑与车机时钟约差1秒，服务器认证通过，但未独立读取服务端时钟。

电脑网络、车机网络及系统DPI未改变；即使电脑与车机仍同一局域网，上述访问实际走公网frps。尚未验证双方异地网络切换、服务器重启、长时间后台或断网重连，因此不声称长期稳定性已通过。

测试结束保留车机FRP及电脑端visitor运行；停止车机远程连接可在远程页点击停止连接。电脑端配置含凭证，仅保存在本地私有测试目录，不纳入交付源码。未修改APK、GitHub、Release。
