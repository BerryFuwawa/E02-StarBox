# FRP异地ADB修正

2026-10-06，修复已写入软件并通过公网覆盖安装。旧版在旧电脑IP无法匹配新车机网络时生成全阻止规则，误拦本机回环，导致FRP无法连接本机5555。

现在自动维护会暂停旧电脑的局域网访问，保留本机回环通道，并检查实际活动规则，发现本机通道丢失时恢复。未放宽外部来源，手动关闭无线ADB仍停止TCP访问。

新版实车跨公网ADB、普通网页和Root网页重复测试通过。状态中的无线ADB开启/关闭表示局域网访问；暂停局域网时FRP本机通道仍可用。此前临时规则已由新版生成规则替换。长时间稳定性仍需观察。

详见[连接状态修正验收](连接状态修正验收.md)。未上传GitHub。
