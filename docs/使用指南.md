# 使用指南

适用于当前 1.5 版本。准备好电脑、车机和同一个 Wi-Fi；需要 root 的功能须先在 EVCC 等工具中运行授权命令。

先从 [版本下载页](https://github.com/BerryFuwawa/Galaxy-E02-tools/releases/tag/v1.5) 获取 APK 并安装。在车机桌面打开「E02 命令回传助手」。

## 连接电脑网页

1. 在车机打开 **E02 AI 连接助手**。
2. 选择 root 有效时间，例如 **0 小时、10 分钟**。需要一直使用，可勾选 **永久有效**。
3. 点击 **复制桥接命令，去 EVCC 粘贴执行**。
4. 到 EVCC 的命令面板粘贴，点击 **ROOT 执行**。
5. 返回助手，等待 root 检测成功。需要在电脑执行 root 命令时，勾选 **允许本次网页会话执行 root 命令**。
6. 点击 **启动局域网命令回传**。
7. 在电脑浏览器打开显示的网址，输入本次四位连接码，点击 **验证连接**。

网页中选择执行权限、输入命令，再点击 **执行并返回结果**。命令直接填写，不加 `adb shell`。下方会显示输出、错误信息和退出码，也可以保存为 TXT。

只使用普通应用权限时，可以直接启动回传。截图和 ADB 开关需要 root。

## 无线 ADB

1. 完成上面的 root 检测，让电脑和车机连接同一 Wi-Fi。
2. 在助手里填写 **电脑的 IPv4 地址**。Windows 可在终端运行 `ipconfig`，查看当前 Wi-Fi 的 IPv4 地址。
3. 点击 **读取 ADB 开关实际状态**，再打开 **无线 ADB** 开关。
4. 电脑安装 Android Platform Tools，在终端执行：

```sh
adb connect 车机IP:5555
adb devices
```

将「车机IP」替换为助手里显示的实际地址。列表显示 `device` 即已连接。

电脑或车机地址变化后，需要重新填写并开启。关闭无线开关不影响有线 ADB。

当前基线按同一 Wi-Fi 连接使用；车机热点、电脑热点及其他网络方式的统一适配将在后续版本完善。

## 有线 ADB

完成 root 检测后，打开 **有线 ADB** 开关，再连接电脑和车机 USB。必要时重新拔插 USB；电脑运行 `adb devices` 查看是否连接。

此开关针对星舰 7 的 USB 模式。开关打开只表示模式已设置，实际能否连接还取决于数据线、USB 端口和电脑驱动。

## 悬浮窗与截图

首次使用时，允许软件 **显示在其他应用上层**，并打开 **显示 E02 AI 悬浮保活窗口**。

- **点击**：截图保存到车机的「下载 / Download」文件夹，截图中自动隐藏悬浮窗。
- **长按**：回到助手。
- **拖动**：移动悬浮窗。

保持回传启动，可以切到其他软件；系统仍可能清理后台。截图需要 root 可用。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 显示 root 不可用 | 重新复制命令，到 EVCC 点击 ROOT 执行，再返回助手 |
| 修改了有效时间 | 重新复制命令并在 EVCC 执行后才会生效 |
| 网页打不开 | 检查电脑和车机是否在同一 Wi-Fi，助手是否仍在运行，网址是否为最新地址 |
| 四位码无效 | 使用车机当前显示的连接码；停止或重新启动后旧码失效 |
| 无线 ADB 连不上 | 确认填写的是电脑 IP，root 有效，无线开关已打开，路由器允许设备互访 |
| 截图失败 | 重新确认 root 授权有效，并检查下载目录是否有可用空间 |

使用结束后，点击 **停止回传及 root 桥接，作废连接码**。这会结束命令回传和 root 授权，但不会自动关闭已经开启的 ADB；需要时分别关闭 ADB 开关。
