# ADB 与命令回传

[返回使用指南](../使用指南.md)

## 无线 ADB

1. 需要修改 ADB 设置时先完成 [Root 授权](Root授权与手机助手.md)。
2. 选择车机要用于电脑连接的局域网地址。
3. 填写允许连接的电脑 IPv4，点击「确认并应用」。编辑中的地址显示「待应用」，不会替换已经生效的地址。
4. 无线 ADB 关闭时，保存 IP 不会自动开启；再点击对应「开启」。
5. 电脑运行 `adb connect 车机IP:5555`，以实际连接结果为准。

| 状态 | 含义 |
| --- | --- |
| 无线ADB - 已开启 - 已允许上述IP使用 | 局域网访问已开启，指定电脑 IP 的规则已检测生效；不代表电脑已经连接 |
| 无线ADB - 已开启 - 未允许上述IP使用 | 局域网访问已开启，但当前电脑 IP 未检测到对应放行规则 |
| 无线ADB - 已关闭 | 局域网无线 ADB 已关闭；供 FRP 使用的本机 ADB 可以继续监听 |
| 状态未知／放行状态未知 | 检测失败、权限不可用或信息不完整，不等同于关闭 |

合法的跨网段 IPv4 可直接放行，并显示「本次为跨网段IP」。网络必须有可用路由；NAT 转换了来源地址时，填写车机实际看到的来源 IP。后台维护保留用户选择的接口，接口临时消失时暂停局域网访问，重新出现后恢复。没有按时间或早上自动关闭的功能。

文字、状态灯和右侧开关按钮按同一份实际检测结果更新。绿色表示已开启、红色表示已关闭、灰色表示未知。点击操作后等待检测完成；失败不会显示成成功。

没有局域网地址时，先连接 Wi-Fi 或开启车机热点，再开启供电脑直连的无线 ADB。跨网段、待应用、未放行、未知及操作失败等提示使用黄色。关闭局域网无线 ADB 不会停止 FRP 所需的本机 ADB，也不会改变 USB 模式。

## 有线 ADB

「有线ADB - 已开启」表示 USB ADB 模式已开启，不代表已经接线或电脑已识别。连接数据线后，使用 `adb devices` 验证。关闭恢复普通 USB 模式。检测失败显示灰色未知状态。

## 网页命令回传

1. 点击「启动命令回传」，浏览器打开显示的网址，输入当前连接码。
2. 普通模式可以执行应用权限内的命令；需要 Root 时先确认授权，再勾选「允许本次网页执行 Root 命令」并启动。
3. 结果包含标准输出、错误输出和退出码。每条网页命令最多执行 30 秒。

停止回传会使旧连接码失效，但保留当前 Root 授权。Root 仍有效时可以直接重新勾选并启动，无需再点击检测。运行中的普通网页不会自动升级到 Root。Root 失效后相关权限关闭，需要重新授权。

默认网页端口为 8875。没有局域网地址时仍可启动本机服务，通过已经配置好的 FRP 访问；手机助手仍需要同一局域网。换网更新局域网网址，本机穿透入口保留，当前网页连接码不因地址变化而重新生成。

「退出程序及后台」结束星匣后台服务和授权，保留当前系统 ADB 设置。请仅在安全驻车时操作，不执行不了解用途的命令。
