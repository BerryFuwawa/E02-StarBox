# ADB 与命令回传

[返回使用指南](../使用指南.md) · [先完成 Root 授权](Root授权与手机助手.md)

## 无线 ADB：电脑与车机在同一网络

1. 在电脑查看当前 IPv4。Windows 可运行 `ipconfig`，选取连接车机网络的 Wi-Fi 或以太网地址。
2. 打开星匣「连接」，确认车机当前网络地址。
3. 填写「允许连接的电脑 IPv4」，点击「确认并应用」。编辑后显示「待应用」时，旧地址仍然有效。
4. 开启无线 ADB，再点击「检测实际状态」。
5. 电脑安装 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)，运行：

```sh
adb connect 车机IP:5555
adb devices -l
```

例如车机地址为 `192.168.1.20`：

```sh
adb connect 192.168.1.20:5555
```

无线 ADB 关闭时，「确认并应用」只保存电脑 IP，不会自动开启。开启后会应用该地址；电脑换网或地址变化时应重新填写并确认。

车机热点、电脑热点和外部 Wi-Fi 都使用当前可互通的网络地址。软件自动识别车机网络，**电脑 IP 仍需用户填写并确认**；不会自动更改电脑网络。真实车机热点／电脑热点链路仍待进一步验证。

## 如何理解状态灯

| 显示 | 含义 |
| --- | --- |
| 无线ADB - 已开启 - 已允许上述IP使用 | 无线服务和该电脑地址的访问规则已生效，仍需电脑实际连接验证 |
| 无线ADB - 已开启 - 未允许上述IP使用 | 服务开启，但当前填写的电脑地址未通过访问规则检查 |
| 无线ADB - 已关闭 | 当前局域网无线访问未开启 |
| 有线ADB - 已开启 | USB ADB 模式开启，不代表电脑已插上线或已识别 |
| 灰灯 | 检测中或状态未知 |

开启绿灯，关闭红灯。网络变化后，会暂停不匹配的电脑访问；返回同一网络后尝试恢复已保存的电脑地址。启用 FRP 时可保留其 ADB 通道。**主动关闭无线 ADB 会同时影响 FRP 的 ADB 通道。**

## 有线 ADB

完成 Root 授权后开启有线 ADB，连接支持数据传输的 USB 线，在电脑运行 `adb devices -l`。必要时拔插 USB。是否需要特定 USB 接口、厂家调试页面或驱动，取决于车机；软件开启 USB 模式不能替代这些条件。

## 网页执行命令

1. 在「连接」点击「启动命令回传」。
2. 电脑浏览器打开星匣显示的网址，默认 `http://车机IP:8875/`。
3. 输入该区域显示的四位连接码；它与手机助手连接码独立。
4. 输入命令，点击「执行并返回结果」。页面显示输出、错误、退出码与是否超时。

需要 Root 命令时，先完成授权并「重新检测 Root」，在启动回传前勾选「允许本次网页执行 Root 命令」。正在回传时不能修改权限；先停止回传，再检测、勾选并重新启动。

按钮第一行为「启动命令回传 / 停止回传」，第二行为「复制连接信息 / 查看诊断结果」。停止后旧连接码失效；车机 IP 改变后需停止并重新启动回传。

## 连接不上时

先核对电脑和车机地址、当前生效电脑 IP、状态文字、服务是否启动，再检查热点隔离、路由器规则、电脑防火墙或 USB 驱动。星匣只修改自己管理的访问规则，不关闭整个系统防火墙。

长命令可用手机助手发送到车机剪贴板。不执行来源不明或不了解用途的命令。
