# FRP 远程连接

[返回使用指南](../使用指南.md)

FRP 让电脑与车机处于不同网络时，仍能访问车机网页和 ADB。车机需要持续运行并能访问服务器，可使用 Wi-Fi 或车机流量；Wi-Fi 开启但没有连接，不会阻止 FRP 启动。服务器显示已连接不代表两条通道均可用，仍需从电脑实际访问。

## 自建服务器或服务商提供地址、Token

1. 打开「远程 → 服务器配置 → 自建服务器 · 私密连接」。服务商支持 STCP 时也可使用。
2. 填写服务器地址、端口、Token、穿透密钥和可选用户名，点击「保存配置」。
3. 在远程首页选择「远程ADB」和／或「打开网页回传」，点击「启动远程连接」。星匣准备所选服务，不必先回连接页分别打开。
4. 查看日志，确认所选通道已启动；电脑运行对应连接配置后实际验证。

| 字段 | 填法 |
| --- | --- |
| 服务器地址 | IP 或域名，不带 http(s):// 和端口 |
| 服务器端口 | 默认 7000，按服务器实际值填写 |
| 用户名（可选） | 服务商提供则填写，否则留空；不是密码 |
| Token | 服务器提供的认证 Token |
| 穿透密钥 | 车机与电脑共享的密钥，至少 16 个字符；可保留自动生成值 |

Token 和穿透密钥不能互相替代。长内容可用手机助手填写。服务商要求时间误差不超过 15 分钟时，应校准设备时间，不是设置每 15 分钟重连。

进入远程页会检测 Root 和本机 ADB。ADB 已可用时，不要求星匣拥有 Root；ADB 未开启且没有 Root 时提示「请提权」。新网页按检测到的权限显示 Root／无 Root；已有网页沿用当前权限，不自动升级。Root 在启动前失效时会提示重新授权。

运行中不能改通道或服务器配置，停止后再修改。停止 FRP 不会结束 Root 或关闭系统 ADB。手动停止后不会因换网自动启动。

### 电脑端

点击「复制电脑端连接配置」，通过手机助手接收，保存为 UTF-8 的 `visitor.toml`。从 [FRP 官方版本](https://github.com/fatedier/frp/releases/tag/v0.71.0) 获取对应平台 frpc，建议与内置 0.71.0 一致。

Windows：

```powershell
.\frpc.exe -c .\visitor.toml
```

macOS／Linux：

```sh
./frpc -c ./visitor.toml
```

网页打开 `http://127.0.0.1:8875/`，输入车机当前网页连接码。ADB：

```sh
adb connect 127.0.0.1:8556
adb -s 127.0.0.1:8556 shell id
```

这些地址属于运行 frpc 的电脑。不能直接在另一台设备打开，也不是使用服务器公网 IP 加 8875／8556。修改用户名、Token、密钥或通道后，重新导出电脑配置并重启电脑 frpc。

## 第三方完整配置

选择「第三方服务 · 导入配置」，用手机助手或文件导入 TOML／YAML／JSON，填写服务商提供的网页根地址，保存启动。页面显示「按导入配置运行」，不会使用自建通道开关修改未知配置。

网页代理建议指向车机 `127.0.0.1:8875`，ADB 指向 `127.0.0.1:5555`。实际网页端口以正在运行的服务为准。导入模式不自动准备任意代理所需服务，网页和 ADB 需按配置在连接页开启。旧配置中的局域网 IP 不会自动替换，换网前请核对。

## 端口与换网

| 服务 | 默认值 |
| --- | --- |
| frps 服务端 | 7000 |
| 车机网页 | 8875，以实际运行端口为准 |
| 车机 ADB | 5555 |
| STCP 电脑网页 | 127.0.0.1:8875 |
| STCP 电脑 ADB | 127.0.0.1:8556 |

自建模式使用本机入口，换网不用重填车机 IP。默认网络变化后刷新自动 DNS 并重连；用户明确配置的 DNS 保留。手机助手不加入穿透，需要与车机处于同一局域网。

登录失败检查服务器、Token、时间；登录后代理失败检查名称冲突与服务商限制；网页失败检查服务和连接码；ADB 失败检查本机 ADB 与电脑 frpc。车辆休眠或失去网络后不能保证可访问，详情见[兼容性与使用须知](../版本验证范围.md)。
