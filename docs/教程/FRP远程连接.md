# FRP 远程连接

[返回使用指南](../使用指南.md)

FRP 让电脑与车机处于不同网络时，仍能访问车机命令网页和 ADB。车机必须持续开机并能访问服务器。只显示「已连接服务器」不代表两条通道都可用，还需检查日志并从电脑连接。


## 自建服务器或服务商提供地址、Token

1. 车机先在「连接」启动命令回传；要使用 ADB 则完成 Root 授权并开启无线 ADB。
2. 打开「远程 → 服务器配置 → 自建服务器 · 私密连接」。服务商提供兼容的 STCP 服务时也可用此入口。
3. 按下表填写，选择网页、无线 ADB 或两者，点击「保存配置」。
4. 点击「启动远程连接」，再查看日志。服务器连接成功后，应能看到所选服务的 `start proxy success`；只有登录成功还不够。

| 字段 | 填法 |
| --- | --- |
| 服务器地址 | 服务器 IP 或域名，不带 `http://`、`https://` 和端口 |
| 服务器端口 | frps 连接端口，默认 7000；按实际服务器填写 |
| 用户名（可选） | 服务商提供则填写，没有则留空；不是登录密码 |
| Token | 服务器提供的认证 Token |
| 穿透密钥 | 车机与电脑共享的私密连接密钥，至少 16 个字符；可保留自动生成值 |

Token 与穿透密钥用途不同，不能互相代替。长内容可使用[手机助手](Root授权与手机助手.md)填写。服务商若要求客户端与服务端时间误差不超过 15 分钟，应校准设备时间；这不是设置每 15 分钟重连。


### 配置电脑端

1. 星匣点击「复制电脑端连接配置」，通过手机助手接收并传到电脑，保存为 UTF-8 的 `visitor.toml`。注意不要保存成 `visitor.toml.txt`。
2. 从 [FRP 官方 Releases](https://github.com/fatedier/frp/releases/tag/v0.71.0) 下载适合电脑系统的 frpc，建议与内置版本 0.71.0 一致。
3. 在配置所在目录运行：

```powershell
.
rpc.exe -c .
isitor.toml
```

macOS / Linux：

```sh
./frpc -c ./visitor.toml
```

4. 保持电脑端 frpc 运行。网页打开 `http://127.0.0.1:8875/`，输入车机命令回传的连接码。
5. ADB 运行：

```sh
adb connect 127.0.0.1:8556
adb -s 127.0.0.1:8556 shell id
```

这些 `127.0.0.1` 地址由**运行 frpc 的电脑**访问，不能直接在未运行对应配置的手机或另一台电脑打开。服务器公网 IP 加 8875 或 8556 不是此私密模式的访问方式。

用户名、Token 或穿透密钥修改后，重新导出电脑配置并重启电脑端 frpc。同一服务器上的服务名称应避免冲突；当前默认名称为 `e02-console`、`e02-adb`，用户名可用于区分不同客户端。

## 第三方服务提供完整配置

1. 选择「第三方服务 · 导入配置」，选择 TOML / YAML / JSON。
2. 用手机助手填写完整配置，或「从文件导入配置」。
3. 填写服务商提供的远程网页地址，只填写 `http(s)://域名:端口`，不带查询参数或子路径。
4. 核对网页通道指向车机当前命令回传 IP 和实际端口，默认 8875；ADB 通道指向 `127.0.0.1:5555`。
5. 保存后启动。映射端口、域名与电脑访问方式按服务商配置使用；「复制电脑端连接配置」仅用于自建私密模式。

导入配置不会自动重写其中的 IP 和端口；车机换网或旧配置使用旧端口时，需自行更新。手机助手本次不加入穿透。

## 端口别填混

| 服务 | 默认值 | 用途 |
| --- | --- | --- |
| frps 服务端 | 7000 | 车机、电脑连接服务器 |
| 车机命令网页 | 8875 | 车机实际网页服务；以「连接」显示为准 |
| 车机 ADB | 5555 | 车机 ADB 服务 |
| 私密模式电脑网页 | 127.0.0.1:8875 | 电脑浏览器访问 |
| 私密模式电脑 ADB | 127.0.0.1:8556 | 电脑 ADB 连接 |
| 手机助手 | 弹窗显示的地址与端口 | 仅局域网手机配对 |

服务商提供的 HTTP / HTTPS 公共代理端口，只有其配置使用 HTTP / HTTPS 代理时才相关；自建私密 STCP 模式无需填写这些端口。

## 排查问题

- 登录失败：核对服务器、端口、Token、设备时间和服务器是否允许连接。
- 登录成功但代理失败：查看日志是否出现名称重复、权限限制或密钥配置问题。
- 网页不可用：确认车机已启动命令回传、电脑端 frpc 在运行、连接码为当前值。
- ADB 不可用：确认无线 ADB 已开启、电脑端 ADB 服务已连接；主动关闭车机无线 ADB 会关闭此通道。
- 换网后掉线：保持车机联网，查看是否正在重连；第三方配置的网页本地 IP 可能需要更新。

当前版本已在真实非局域网环境验证网页普通／Root 命令和 ADB 通道。长时间运行及锁车唤醒仍需继续验证，车辆休眠后不能保证远程可用。
