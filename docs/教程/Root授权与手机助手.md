# Root 授权与手机助手

[返回使用指南](../使用指南.md)

## 授权

1. 打开星匣「连接」，点击「复制提权命令」。成功复制后自动显示操作说明。
2. 任选一种已有授权工具执行：

| 工具 | 操作 |
| --- | --- |
| EVCC | 终端 → 粘贴到自定义命令【命令】输入框 → 点击 Root 执行 |
| 应用管家 | 执行命令 → 粘贴命令 → 本机执行；执行环境必须已有 Root |

3. 返回星匣，点击「重新检测 Root」。绿色状态表示检测到有效授权；复制命令本身不代表授权成功。

不再设置授权时长。车机重启或后台被系统停止等情况可能导致 Root 授权失效，需要重新授权。点击「结束提权」或「退出程序及后台」会结束当前授权。切换页面、切到其他应用或仅停止网页回传不会主动结束授权。

「结束提权」只需一次确认；取消保留授权。当前系统 ADB 配置保持不变。星匣不会因执行这个命令成为系统级 Root 应用，也不会安装开机恢复任务。

从 v1.7.0 升级：原来已经运行的限时授权仍按旧规则结束，不会自动延长。重新复制并执行新版命令后使用新规则。旧时长设置无需清除，其他配置继续保留。

## 手机输入与双向复制

1. 手机和车机连接同一局域网，点击顶部「手机助手」。
2. 扫码打开网页，输入四位连接码。也可在手机浏览器输入弹窗网址。连接成功后本弹窗自动关闭。
3. 在星匣点选输入框，手机确认目标字段，再点击「粘贴到焦点」。仅支持星匣的输入框。
4. 向 EVCC 等其他应用传文本时，使用「发送到车机剪贴板」，再在车机上粘贴。

星匣复制的命令或配置可直接在手机接收。「同步其他应用复制的内容」在设置中开启，默认关闭。敏感内容默认遮罩，不保存历史；手机不支持一键复制时，可选中文本后长按复制。

已有有效手机连接时，点击顶部入口提示「已连接」。关闭二维码弹窗不会停止服务；设置中可解除连接、刷新连接码。退出程序后旧会话失效。

域名、IP 和端口默认使用星匣小数字键盘；需要输入字母时点击「车机输入法输入」，也可使用手机助手填写或导入。「完成」只关闭键盘，配置仍需确认或保存。
