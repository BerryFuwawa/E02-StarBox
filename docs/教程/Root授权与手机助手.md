# Root 授权与手机助手

[返回使用指南](../使用指南.md)

## 启用独立授权

1. 在车辆安全驻车时打开「连接」，点击「启用独立授权」。
2. 阅读确认窗口，确认后等待检测。本机已有 Root ADB 可用时，星匣建立自己的 Root 服务；只有实际检测通过才显示绿色状态。
3. 检测失败时查看页面原因。可点击「重新检测 Root」重试；不要把安装成功或按钮点击成功当作获得 Root。

**前提是车机本机已有可用的 Root ADB。** 普通 ADB 不等于 Root ADB；星匣不会为原厂未开放的系统解锁 Root，也不会自动为其他应用授予 Root。

新版不再需要把星匣提权命令复制到 EVCC 或应用管家执行。已确认允许独立授权后，星匣在本机条件可用时尝试恢复；没有设置授权倒计时。车机重启、休眠或后台被系统停止后仍可能失效，请以实际检测结果为准。

「结束提权」需要一次确认，取消则保留授权；结束后不会自动重新获取，需要再次确认启用。「退出程序及后台」也会结束当前授权与星匣服务，保留系统已有 ADB 设置。仅停止网页回传或 FRP 不会结束 Root 授权。

## 手机输入与双向复制

1. 手机和车机连接同一可互通局域网，点击顶部「手机助手」。
2. 扫码打开网页，输入四位连接码。也可在手机浏览器输入弹窗网址。连接成功后本弹窗会自动关闭。
3. 在星匣点选输入框，在手机确认目标字段，再点击「粘贴到焦点」。仅支持星匣自己的输入框。
4. 向 EVCC 等其他应用传文本时，使用「发送到车机剪贴板」，再在车机上粘贴。

星匣复制的内容可直接在手机接收。「同步其他应用复制的内容」在设置中开启，默认关闭。敏感内容默认遮罩，不保存历史；手机不支持一键复制时，可选中文本后长按复制。

已有有效手机连接时，点击顶部入口提示「已连接」。关闭二维码弹窗不会停止服务；设置中可解除连接、刷新连接码。退出程序后旧会话失效。

地址和端口默认使用星匣小数字键盘；需要输入字母时点击「车机输入法输入」，也可使用手机助手填写或导入。「完成」只关闭键盘，配置仍需确认或保存。
