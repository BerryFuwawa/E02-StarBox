# 初始化与配置保留

## 更新时保留配置

官方同签名 APK 可覆盖安装，保留服务器、连接、更新线路和后台选项。日常更新无需初始化。

## 初始化前

初始化会清除星匣自己的设置、连接凭证、Root 授权和首次使用确认。请先把需要的服务器地址、端口、Token、穿透配置及更新线路保存在安全位置。敏感内容不要公开发送。

当前版本没有应用内一键备份／导入整套设置的入口；初始化后需要重新填写配置和确认授权。

## 操作步骤

1. 在【设置】点击【初始化】。
2. 阅读清除范围，确认需要重置后点击【确认初始化】；取消不会清除。
3. 软件关闭后重新打开，阅读首次【免责声明与风险告知】。
4. 重新配置 Root、远程服务器及后台选项。系统辅助保活或悬浮窗权限如有变化，按页面提示重新设置。

初始化只重置星匣，不恢复车机出厂设置，不修改系统 ADB，不删除下载文件夹里的截图。网页、手机和 FRP 连接会停止，旧连接信息不再使用。
