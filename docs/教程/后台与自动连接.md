# 后台与自动连接

## 打开星匣时自动连接

1. 打开【远程】→【服务器配置】，填写并保存配置。也可导入服务商提供的配置。
2. 自建服务器模式下选择需要的【远程ADB】、【网页回传】通道；建议先手动启动，确认配置可用。
3. 勾选【软件打开自启内网穿透】。它默认关闭，勾选会保存，下次重新启动软件后生效。

星匣每次重新启动时尝试一次，不会因切换菜单或点击【停止连接】又自动启动。已运行时不重复启动。软件一直留在后台时，单纯返回页面不算重新启动。

自建服务器模式下，星匣准备所选服务后连接服务器。已有网页服务沿用原来的 Root 权限；ADB 未开启且无可用 Root 时提示先提权。自动启动不会代替用户确认独立授权。第三方导入配置按原配置运行。

配置未填写、权限不足或网络不可用时，在【远程】查看提示，处理后可点击【启动远程连接】。取消勾选只影响未来的自动启动；停止当前连接请点击【停止连接】。

## 开机自启与主动退出

【后台】中的【开机自启】在系统完整开机通知到达时尝试运行，不影响右上角【退出程序及后台】，退出后仍保留勾选。主动退出后，换网、后台重试和升级通知不会立即重新拉起程序。

【星匣后台保活】仍限制主动退出：先关闭总开关，再点击退出。它下方的状态栏和悬浮窗选择会被记住，不用逐项取消。

本版暂时隐藏、停用【熄火后远程连接保活】。熄火、休眠后发动车辆并不一定是系统完整开机；如果星匣没有运行，请手动打开。开机自启和熄火唤醒自动恢复仍需分别进行实车验证。
