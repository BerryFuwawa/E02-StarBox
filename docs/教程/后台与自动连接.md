# 后台与自动连接

## 开机和上车后自动运行

1. 在【连接】完成 Root 授权，确认实际状态正常。
2. 在【后台】开启【星匣后台保活】和【开机自启】。
3. 需要顶部入口时，开启【状态栏保活】。
4. 点击【系统辅助保活】，阅读说明后选择【启用并修复】，等待显示【已启用】。
5. 在【远程】保存服务器配置，先手动启动并确认网页和 ADB 可用。

车辆自然唤醒或系统完整启动后，星匣按已保存的选择恢复后台和远程通道。只有实际授权有效时才执行 Root 操作；本机缺少可用的 Root ADB 时，可能仍需应急提权。

系统辅助保活仅处理星匣自己的服务，保留其他应用条目。状态栏图标提供返回入口，不代表所有远程通道都已连接，仍需查看实际状态。

## 打开软件时自动连接

在【远程】勾选【软件打开自启内网穿透】。建议先手动验证服务器配置。下次重新启动软件时尝试连接，切换菜单不会重复启动。

自建模式按所选的【远程ADB】【网页回传】准备本机服务；导入模式按原配置运行。已有网页服务沿用实际权限，不会自动将普通网页升级为 Root。

## 断网与换网

网络恢复后重新尝试连接；自动获取的地址和 DNS 随网络更新。用户主动停止的通道保持停止，不因切换菜单或恢复网络重新开启。

车机热点、电脑热点和外部 Wi-Fi 需要设备之间可以互通；热点隔离、服务器故障或移动网络限制仍会影响访问。手机助手只在局域网使用。

## 普通和无感悬浮窗

开启【星匣后台保活】与【保活悬浮窗】后，可选择【无感悬浮窗】。无感模式全透明、不接收点击或拖动；父项关闭时该选项置灰，并保留选择。

取消无感模式后，普通悬浮窗支持点按返回、长按截图、按住拖动；截图保存在下载文件夹。拖不动时点击【恢复悬浮窗到屏幕中央】。截图需要有效 Root。

## 退出与供电

退出前先关闭【星匣后台保活】；仅开启【开机自启】不限制主动退出。同次开机内主动退出后，不会由旧恢复任务立即拉起。退出结束当前 Root、网页、手机和 FRP 服务，保留系统 ADB 配置。

星匣不阻止原厂休眠、不绕过低电量保护。需要离车后保持中控供电时，在原厂设置选择【离车不下电 → 常开】并启用。完整重启可能重置该原厂选项，需要重新检查。

旧研究版启用了离车供电模式时，可使用【结束旧模式，保留原厂供电】清理旧选择；不会更改当前原厂供电设置。
