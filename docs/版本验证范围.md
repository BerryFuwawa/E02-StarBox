# 兼容性与使用须知

主要测试车型为 **2025 银河星舰 7 / E02**，系统为 **Flyme Auto 2.5.0、Android 9**，屏幕分辨率为 1920×1080。其他车型或系统版本可能存在差异。

## 使用前需要什么

- 修改 ADB、截图及软件内安装更新需要有效 Root 授权。新版独立授权需要车机本机已有可用的 Root ADB，安装星匣不会为原厂系统解锁 Root。
- 手机助手需要手机与车机处于可互通的局域网。
- FRP 需要可用服务器及网络，车机和电脑端均需正确配置。

## 连接与后台

车机休眠、重启、断网或系统清理后台后，授权和连接可能失效。重新打开星匣，检查实际状态，按需恢复服务。

「软件打开自启内网穿透」在软件重新启动时尝试一次；手动停止后不因切换菜单再次启动。「开机自启」依赖系统完整开机通知，不等于熄火唤醒恢复。本版已隐藏、停用熄火后远程保活，不承诺锁车期间持续在线。

绿色状态表示对应服务或设置已启用，是否能从电脑访问仍需实际连接验证。

## 验证范围

v1.7.4 已在上述车机覆盖安装，检查自动穿透、退出、配置入口、普通／Root 网页命令和 FRP ADB。详细结果见[v1.7.4 验证记录](1.7.4验证记录.md)。

完整冷启动自启、车机热点、电脑热点、车机流量连续换网、长期后台连接及完整初始化仍需进一步实测。没有文件选择器的车机使用手机助手导入配置。

初始化会清除星匣设置，请先保存需要的配置。请仅在车辆安全驻车时操作。
