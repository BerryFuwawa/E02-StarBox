## 本批已验证

- 编译、原签名、包名与版本；覆盖安装、配置保留、车机 APK 与交付一致。
- Root 取消和结束、重新授权、旧限时参数拒绝、命令超时；授权忙碌时不误判失效。
- 普通与 Root 网页、停止再启用、实际 FRP 网页及 ADB 通道；没有星匣 Root 时可使用已有 ADB。
- Root 卡片置顶、下方两卡并排、授权说明弹窗及当前 ADB 状态。
- 车机手动更新检查直连成功；电脑下载线上 APK 并核对大小、哈希、包名及原签名成功。
