# 兼容性与使用须知

主要测试车型为 **2025 银河星舰 7 / E02**，系统为 **Flyme Auto 2.5.0、Android 9**，屏幕分辨率为 1920×1080。其他车型或系统版本可能存在差异。

## 使用前需要什么

- 修改 ADB 设置、截图和软件内安装更新，需要有效的 Root 授权。EVCC 或应用管家本身必须能够执行 Root 命令；安装星匣不会自动获得 Root。
- 手机助手需要手机与车机处于可互通的局域网。
- FRP 远程连接需要可用的服务器和网络，车机端与电脑端都要正确配置。

## 连接可能中断的情况

车机休眠、重启、网络断开或系统清理后台后，授权和连接可能失效。重新打开星匣，检查 Root 状态，并按需启动网页回传和远程连接。

本版没有开机或锁车后自动恢复远程连接的功能。绿色状态灯表示相应服务或设置已启用，是否能从电脑访问仍需实际连接确认。

## 尚需继续测试的场景

车机热点、电脑热点、车机流量、连续换网以及长时间后台连接尚未完成充分测试。当前版本不承诺车辆休眠后仍能保持远程访问。

初始化会清除星匣设置，请先保存所需配置。完整初始化流程尚未完成实车测试。

开发者可查看[v1.7.3 测试记录](1.7.3验证记录.md)，了解实际测试范围。
