# 兼容性与使用须知

主要验证环境：**2025 银河星舰7 / E02、Flyme Auto 2.5.0、Android 9、1920×1080**。其他车型和系统版本可能不同。

## v1.7.6稳定基线范围

ADB管理、独立授权和应急提权、普通／Root网页命令、FRP网页与ADB通道、手机输入与复制、状态栏与悬浮窗、软件更新、事件日志及初始化。

开机和自然唤醒恢复、断网与换网恢复也纳入本版基线。实际成功与用户开关、授权、原厂供电和网络有关。

## 已有实车结果

- 本车当前恢复机制取得自然唤醒后的自动运行、状态栏与远程连接成功记录。
- 2026年10月16日，同一恢复机制的显示研究包完整中控重启后约61秒自动恢复网页、ADB、Root和状态栏。v1.7.6保留该机制，本批没有再次重启。
- v1.7.6原签名覆盖安装、初始化、首次风险告知、配置恢复、Root身份与命令、网页普通／Root及FRP ADB通过。
- 初始化后重新恢复星匣自己的系统辅助绑定，保留其他应用条目；原厂常开和系统ADB保持。
- 软件内完整下载、校验、确认安装与配置保留已有实车记录。

## 仍需持续验证的场景

所有热点组合、连续换网、不同服务器与长时间运行尚未穷尽。没有把本次未执行的断网、换网或再次重启记作新增实测。首次Root仍要求已有可用授权入口，安装星匣不会解锁原厂Root。

正常休眠或断电期间不保证远程在线；不提供阻止原厂休眠的保证。仪表／HUD文字、箭头、自定义图形和投屏不在本版本中。

详细记录见[v1.7.6验证记录](1.7.6验证记录.md)。
