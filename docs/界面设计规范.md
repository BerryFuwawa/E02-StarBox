# E02星匣界面设计规范

本应用的提示、确认、配置、日志、手机助手、授权说明及首次风险告知采用圆角弹窗。正文保持清晰的间距，不使用实时模糊或复杂动效。

- 主弹窗采用24dp圆角；小数字键盘采用16dp圆角及清晰边框。
- 普通操作按钮采用12dp圆角，底色与弹窗区分；紧凑的ADB按钮保持原有配色与较小圆角。
- 主操作使用冰蓝底色，次操作使用石墨底色；停止、结束和初始化等操作使用红色，已有启动/停止配色保持不变。
- 弹窗内容整体按圆角裁剪，内部布局不得用方形底色盖住圆角。保持自定义卡片、输入框和提示区原有样式。
- 正文与操作区分开留白，按钮保持足够触控面积；单独的「明白」「关闭」按钮居中展示。
- Root状态紧跟「Root 提权」标题右侧，以「状态：」开头；颜色仍以实际授权检测结果为准。

系统安装器、权限设置和系统输入法由车机系统绘制，本应用不能统一它们的外观。

## 版本更新

- 右下角使用透明背景、18sp 单行文字和原生红色圆点，触控高度至少48dp；不显示更新简介，不使用大面积色块，不覆盖系统底栏。
- 最新版本不显示入口。自动检查失败不弹窗，仅显示“检测更新失败，点击查看”；点击进入设置中的更新区域。
- 新版本入口采用“发现更新 - 版本号 - 点击查看”。更新简介在24dp圆角石墨弹窗内显示，长正文可滚动，按钮区固定在底部。
- “下载”“安装”“使用”采用冰蓝主按钮，“取消”采用石墨次按钮；双按钮高度一致，均为12dp圆角。
- 网络测试展示当前线路和进度，不同时堆叠五行错误。首条成功后只显示一次保存询问，不自动切换用户线路。
- 下载、安装、检查失败分别给出具体操作建议；技术堆栈和执行命令仅进入私有诊断记录，不出现在普通提示中。
- 本版更新仅使用已有Root授权安装，软件不打开系统安装权限页，不以系统页面存在作为功能可用的依据。

## 公开说明与提示文案

- 首页、更新说明和教程先说明用途、改进和操作方法，使用软件内实际显示的按钮名称。
- 更新说明不写审核进度、上传过程、本地交付路径或开发任务状态；`versionCode`、签名指纹和测试方法放在开发者资料中。
- 每项更新说明用户会看到什么变化；需要授权、重开服务等操作时，给出具体步骤或教程链接。
- 兼容性限制用实际使用场景说明，例如车机休眠后连接可能中断，并说明如何恢复。
- 示例截图的版本号与当前版本不同时明确注明；测试记录区分实车测试与模拟，不将未测场景写成已支持。
