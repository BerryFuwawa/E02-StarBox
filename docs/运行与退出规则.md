# 运行与退出规则

适用于 v1.7.4。

【后台】集中管理运行与恢复；【设置】保留手机助手、版本更新、GitHub 加速线路与初始化。

**星匣后台保活**下有【状态栏保活】【保活悬浮窗】两个独立子项。关闭总开关暂时停用两项但记住选择；重新打开时恢复。状态栏为黑白透明星盒，点击面板按钮回到主界面。悬浮窗点按返回、长按截图到下载文件夹、拖动移动，提供权限与居中按钮。

只有【星匣后台保活】会限制主动退出：开启时退出按钮为灰色，点击可前往【后台】关闭它；关闭后即可使用红色的【退出程序及后台】。

【开机自启】不限制主动退出，也不会被退出操作取消勾选。主动退出停止本次运行，后台重试、换网或升级通知不能立即重新拉起；下一次收到系统完整开机通知时再尝试启动。不同车机的休眠唤醒不一定发送完整开机通知，不能将开机自启等同于熄火唤醒恢复。

【熄火后远程连接保活】暂时隐藏并停用。旧设置保留以兼容升级，但不参与保活、退出和唤醒恢复判断；本版不承诺锁车后持续在线或发动车辆后自动恢复远程连接。

【远程】页新增【软件打开自启内网穿透】，默认关闭，详见[后台与自动连接](教程/后台与自动连接.md)。它与开机自启分别控制：前者在软件重新启动时尝试连接服务器，后者请求系统开机时运行星匣。

退出停止星匣的网页、手机助手、FRP、更新、悬浮窗和当前授权服务，不修改系统已有 ADB 设置，也不停止其他应用。正在安装更新时请等待安装完成。

【启用独立授权】首次需确认。本机已有 Root ADB 可用时建立星匣自己的 Root 服务，实际身份核验后才显示授权成功。结束授权后必须再次确认；不显示旧的复制提权命令或 EVCC／应用管家操作说明。这不是原生首次 Root 解锁。
